ISA-101 Hierarchy #3 Melter System

Display Hierarchy

The system follows a four-level drill-down hierarchy based on ISA-101.01-2015. Each level adds detail — operators start at the site overview and navigate down to specific equipment controls as needed. Click any equipment to drill in; use the sidebar, breadcrumb or Back button to move up.

L1

Site Overview Level 1 — Overview

The highest-level display showing the entire facility at a glance. Circular KPI gauges summarize key process values (temperature, combustion air output, flow rate). A simplified site map shows the remelt red zone with melters #3–#6 and surrounding buildings. An equipment tree lists all major assets with status dots. No control is available from this level — monitoring and navigation only.

Circular KPI Gauges Site Map Equipment Tree 24h Trend Overview Alarm Counter
↓Click melter on map or tree
L2

#3 Melter Area Level 2 — Area / Dashboard

Shows all equipment in the #3 Melter area with live values. Four circular gauges across the top track the primary KPIs. The area schematic maps the physical layout: melter, holder, stack, burners, gas pressure switches (LGPS/HGPS), argon/chlorine system, casting area and mold table. CALP sensors are marked in amber. Equipment is clickable to drill into controls.

Area KPI Gauges Equipment Schematic CALP Sensor Markers Live Temperatures Gas System Layout
↓Click melter or holder
L3

#3 Melter Controls Level 3 — Process Control

The primary operating screen. Temperature setpoint with stepper control, bath and breech temperature with linear gauges, combustion air output. Purge and ignition sequence command buttons, flame control segmented selector (Auto/Low/Flux). Auto/Manual toggle for overall control mode. Two permissive tables (Purge and Ignition) with OK/DAT status chips. The Flow Loop button opens the L4 PID faceplate.

Temperature SP Stepper Linear Gauges Purge Start/Stop Ignition Start/Stop Flame Control Auto/Manual Toggle Permissive Tables Status Banner
↓Open PID Faceplate button
L4

Flow Loop PID Faceplate Level 4 — Detail Popup

Opens as a modal overlay. Single unified vertical gauge with PV arrow (left), OP arrow (right) and SP diamond marker. Alarm limit table (HH/H/L/LL) with status dots. PID tuning parameters (Gain, Rate, Reset). Auto/Manual toggle for the loop controller. Closes back to L3 on dismiss.

Circular KPI Gauges

Ring charts showing key values at a glance. Colour-coded by parameter: cyan for temperature, amber for output, green for flow.

▶

Command Buttons

Cyan for start/enable actions, red outline for stop/destructive actions. 46px minimum height for touch panel use.

▲

Alarm Indicators

Shape + digit + colour redundant coding. Orange for P2 (high), amber for P3 (medium). Banner at the bottom of every screen.

↔

Auto / Manual Toggle

iOS-style switch. Cyan track for Auto, purple track for Manual. Letter inside the thumb (A or M) for redundant coding.

⋮

Trend Charts

Multi-pen SVG trends with colour-coded legend. Available at every level for historical context. Time range selectable.

ISA-101.01-2015 Alignment

This hierarchy follows the ISA-101 display classification: Level 1 provides the overview for situational awareness across the entire facility, Level 2 is the area dashboard for a specific process unit, Level 3 is the primary operating screen where all control actions happen, and Level 4 provides detailed equipment faceplates and diagnostics. Alarm coding uses redundant shape, digit and colour per ISA-18.2. Bright colours are reserved exclusively for alarm and abnormal conditions — the neutral dark canvas keeps operator attention on what matters.
